# Security policy

Nodrail decides whether an AI agent's action may run, so a way around a decision
is a security problem.

Please report vulnerabilities privately, never in a public issue: use **Report a
vulnerability** in the repository's Security tab, or write to hello@nodrail.com.
Include the repository, version and steps to reproduce. We aim to acknowledge
reports within three working days and credit you in the advisory unless you'd
rather we didn't.

Each repository's own `SECURITY.md` lists what counts and which versions get
fixes.
